# Preparación Oficial Red Hat EX180 - OpenShift Application Developer

Este repositorio contiene el material técnico, manifiestos YAML y laboratorios prácticos para la certificación Red Hat EX180.

## Roadmap de Estudio (8 Semanas)
- [x] **Módulo 1:** Fundamentos de CLI (oc), Proyectos y Creación de Aplicaciones
- [x] **Módulo 2:** Configuración de Aplicaciones (ConfigMaps y Secrets)
- [ ] **Módulo 3:** Redes, Servicios y Rutas TLS (Edge, Passthrough, Re-encrypt)
- [ ] **Módulo 4:** Estrategias de Construcción y Source-to-Image (S2I)
- [ ] **Módulo 5:** Almacenamiento Persistente (PV, PVC)
- [ ] **Módulo 6:** Salud de Aplicaciones (Probes) y Control de Recursos
- [ ] **Módulo 7:** Estrategias de Despliegue Avanzadas (Blue-Green, Canary)
- [ ] **Módulo 8:** Simulacro de Examen Práctico en Vivo

## Estructura del Repositorio
- modulo-1-cli-fundamentos/: Comandos esenciales de oc, proyectos y manifiestos de despliegue base.
- modulo-2-configmaps-secrets/: Inyección de variables de entorno, secrets en Base64 y montaje de volúmenes de configuración.
- modulo-3-redes-routes-tls/: Redes SDN, Services, y terminaciones TLS en Ingress Controller.
